# 🕵️ Footprinting & Reconnaissance — Course Notes

Chapter-wise notes from **Module 02: Footprinting & Reconnaissance** (Practical Ethical Hacking Course), reorganized into clean reference files, with extra tools and techniques added from global and Indian OSINT practice.

> ⚠️ **Ethics & legality note:** Everything here is for **authorized** security assessments, bug bounty programs with clear scope, CTFs, or securing your own assets. Running active recon (port scans, banner grabs, credential testing) against systems you don't own or lack written permission for is illegal in most jurisdictions (India: IT Act 2000, Sections 43 & 66; globally: CFAA, Computer Misuse Act, etc.). Passive/OSINT recon on public data is generally lower-risk but still respect platform ToS and privacy laws (GDPR, India's DPDP Act 2023).
